# Il Castello Incantato - PWA Game (Versione 2)

Pacchetto aggiornato con 4 Modalità di difficoltà (compresa la modalità **Adulti / Esperto**)!

## Modalità di Gioco:
1. **Facile (5-6 anni):** Aiuti illimitati, no Game Over.
2. **Normale (7-8 anni):** 5 aiuti, danno standard.
3. **Difficile (9-10 anni):** 3 aiuti, danno aumentato.
4. **👑 ADULTI / ESPERTO:** ZERO aiuti della Lucciola, danni punitivi (-50 HP per errore).

## Come caricare su GitHub:
1. Estrai lo zip.
2. Carica i file nella tua repository GitHub.
3. Attiva GitHub Pages dalle impostazioni repository.
